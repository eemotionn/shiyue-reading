An **agent** is a system that can plan, use tools, and act toward a goal with limited human intervention.

## Core pieces

1. **Goal** — what success looks like
2. **Memory** — short-term context and optional longer notes
3. **Tools** — APIs, browsers, code runners, and so on
4. **Loop** — observe → decide → act → repeat until done or stuck

Agents are useful when a task needs several steps that a single prompt cannot finish cleanly. They are less useful when you already know the exact one-shot answer you want.
